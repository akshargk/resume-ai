## About the Project

ResumeAI is an AI-powered resume analyzer that:

- 📄 Analyzes PDF resumes
- 🤖 Uses AI to evaluate resume quality
- 📊 Generates ATS Score
- ✅ Provides ATS Compatibility
- 💪 Identifies strengths
- 📌 Suggests improvements
- 🛠 Detects technical skills
- 💌 Generates a personalized cover letter

The complete source code, documentation, and latest features are available in the **`day-15-deployment`** branch.
